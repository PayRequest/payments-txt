# Laravel (PHP) Implementation

Reference implementation from [PayRequest](https://payrequest.me) — the platform that built the payments.txt standard.

## Route

In `routes/web.php`, inside your domain group (before any catch-all slug routes):

```php
Route::get('/{handle}/payments.txt', [PaymentManifestController::class, 'show'])
    ->where('handle', '[a-zA-Z0-9\-_]+')
    ->name('payment.manifest');
```

## Discovery tag

Add to your Blade layout's `<head>`:

```html
<link rel="payments" type="text/plain"
      href="https://payrequest.me/{{ $businessName }}/payments.txt">
```

## Controller

```php
<?php

namespace App\Http\Controllers;

use App\Models\PaymentPage;
use Illuminate\Http\Response;

class PaymentManifestController extends Controller
{
    public function show(string $handle): Response
    {
        $paymentPage = PaymentPage::where('handle', $handle)
            ->with('user.businessDetails')
            ->firstOrFail();

        $user    = $paymentPage->user;
        $bd      = $user->businessDetails;
        $domain  = config('salespage.domain', 'payrequest.me');
        $appUrl  = config('app.url');

        $lines = [
            '# PAYMENTS.TXT MANIFEST (X402 COMPLIANT)',
            '# Generated by PayRequest.me for @' . $handle,
            '',
            '[meta]',
            'version                  = "1.0"',
            'status                   = "active"',
            'x402_discovery_url       = "' . $appUrl . '/api/v1/x402/' . $handle . '"',
            'x402_payment_endpoint    = "' . $appUrl . '/api/v1/x402/' . $handle . '/pay"',
            '',
            '[payment_terms]',
            'due_days                 = 14',
            'late_fee_percentage      = 2.0',
            'preferred_fiat           = "' . strtoupper($bd?->currency ?? 'EUR') . '"',
            'preferred_crypto         = "USDC"',
        ];

        $evm    = $user->crypto_wallet_address ?: null;
        $solana = $user->solana_wallet_address ?: null;
        $iban   = $bd?->iban ?: null;
        $bic    = $bd?->bic ?: null;

        if ($evm || $solana) {
            $supported = array_filter([$evm ? '"EVM"' : null, $solana ? '"Solana"' : null]);
            $lines = array_merge($lines, [
                '',
                '[crypto_rails]',
                'supported_standards      = [' . implode(', ', $supported) . ']',
                'primary_stablecoin       = "USDC"',
                ...($evm    ? ['evm_address              = "' . $evm . '"']    : []),
                ...($solana ? ['solana_address           = "' . $solana . '"'] : []),
            ]);
        }

        if ($iban || $bic) {
            $lines = array_merge($lines, [
                '',
                '[fiat_rails]',
                ...($iban ? ['sepa_iban                = "' . strtoupper(preg_replace('/\s+/', '', $iban)) . '"'] : []),
                ...($bic  ? ['sepa_bic                 = "' . strtoupper(trim($bic)) . '"']  : []),
            ]);
        }

        $lines = array_merge($lines, [
            '',
            '[hosted_checkout]',
            'human_fallback_url       = "https://' . $domain . '/' . $handle . '"',
        ]);

        return response(implode("\n", $lines) . "\n", 200, [
            'Content-Type'  => 'text/plain; charset=UTF-8',
            'Cache-Control' => 'public, max-age=3600',
            'X-Robots-Tag'  => 'noindex',
        ]);
    }
}
```

## X402 endpoint (autonomous payments)

See [spec/x402-integration.md](../spec/x402-integration.md) for the full X402 controller.

The settlement script uses **viem** (already installed if you use Base/Solana) — no Coinbase CDP account required:

```env
X402_HOT_WALLET_KEY=0xYourBaseWalletPrivateKey
BASE_RPC_URL=https://mainnet.base.org
```

Source: [scripts/x402-settle.mjs](https://github.com/PayRequest/payrequest/blob/main/scripts/x402-settle.mjs)
